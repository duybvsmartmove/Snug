# Meta Progress & Economy

## Meta Progress
- Level Progression: mỗi chapter khoảng 10–20 level.
- Journey/Chapter: School Day, Weekend Trip, Camping, Beach Vacation, Moving Day...
- Reward sau level: Coin + Memory Item.
- Reward cuối chapter: mở destination mới hoặc collectible.
- Long-term Collection: Scrapbook / Travel Album lưu postcard, sticker, photo, souvenir.

## Economy
- Base có sẵn 350 coin.
- Hoàn thành level: số coin note tại file Level Design (hiện trống).
- Hoàn thành 1 Journey/Chapter: 40 coin.
